The official personal portfolio website for **Arwa Alaa**, highlighting software development skills, technological education at Borg El Arab Technological University, featured web applications, and direct contact avenues.

## ✨ Features

- **Hero & Intro**: Dynamic presentation, animated greeting, CV download trigger, and social profile links.
- **Skills Matrix**: Categorized tech stack (Frontend, Backend fundamentals, UI/UX, Tools) with proficiency indicators.
- **Project Showcase**: Interactive filtering by category with live preview links, source code triggers, and modal previews.
- **Academic & Experience Timeline**: Education details at Borg El Arab Technological University.
- **Interactive Contact Form**: Client-side validation and immediate feedback notifications.
- **Theme & Smooth Navigation**: Sticky glass header, smooth scrolling, and mobile drawer navigation.

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5.
- **Styling**: Vanilla CSS3 with custom variables, glassmorphism, gradient accents, and responsive breakpoints.
- **Logic**: Vanilla ES6+ JavaScript.
- **Typography**: Google Fonts (Space Grotesk, Plus Jakarta Sans).

## 📂 Project Structure
