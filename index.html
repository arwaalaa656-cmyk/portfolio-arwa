How to Add New Projects in the Future

Adding a new project to your portfolio is designed to be effortless! Just follow these simple steps in 03-portfolio-arwa/index.html:

  1. Open index.html and find the #projectsGrid container.
  2. Copy any existing <div class="project-card"> block.
  3. Replace the image URL, project title, description, and technologies.
  4. Set the category attribute (e.g. data-category="fullstack") to match your filter tab.
  5. Paste your GitHub or Live Demo link into the <a href="..."> tag!
